# Just End Portal

**Just End Portal**은 오버월드와 엔드의 원하는 위치에 단방향 엔드 포탈을 생성할 수 있는 Minecraft 모드입니다.

기존 엔드 포탈의 이동 감각을 유지하면서도, 플레이어가 직접 출발 포탈과 도착 위치를 지정할 수 있습니다.

## 개발 환경

* Minecraft 26.1.2
* NeoForge 26.1.2.97

## 주요 기능

### 엔드 포탈 생성기

새로운 블록인 **엔드 포탈 생성기**를 사용하여 오버월드와 엔드 사이에 단방향 포탈을 생성할 수 있습니다.

1. 오버월드 또는 엔드에서 원하는 위치에 엔드 포탈 생성기를 설치합니다.
2. 설치한 생성기는 연결 대기 상태가 되고, 생성기 아이템 하나가 유지됩니다.
3. 연결 대기 상태의 생성기를 반대 차원의 원하는 도착 위치에 설치합니다.
4. 처음 설치했던 생성기가 엔드 포탈로 변하고, 반대 차원에는 커스텀 도착 플랫폼 바닥이 생성됩니다.
5. 포탈에 진입하면 해당 도착 플랫폼으로 이동합니다. 도착 플랫폼 자체는 포탈이 아니므로 이동은 단방향입니다.

오버월드와 엔드에는 각각 하나의 출발 포탈을 만들 수 있으므로, 한 플레이어는 최대 두 개의 독립적인 단방향 포탈을 운용할 수 있습니다.

### 조합법과 해금 조건

엔드 포탈 생성기의 조합법은 다음과 같습니다.

```text
흑요석       튀긴 후렴과   흑요석
튀긴 후렴과  엔드 수정     튀긴 후렴과
흑요석       튀긴 후렴과   흑요석
```

엔드 포탈 생성기 1개를 제작하려면 흑요석 4개, 튀긴 후렴과 4개, 엔드 수정 1개가 필요합니다.

조합법은 엔드 발전과제 **머나먼 휴양지 (Remote Getaway)** 를 달성하면 해금됩니다.

### 커스텀 도착 플랫폼

연결 대기 상태의 생성기를 반대 차원에 설치하면 대응 위치에 커스텀 도착 플랫폼이 생성됩니다.

플랫폼 블록의 충돌 판정은 풀블록이지만, 외형은 우는 흑요석 반블록이 블록 중앙에 떠 있는 것처럼 렌더링되며 부유 애니메이션이 적용됩니다.

포탈에 진입할 때마다 플랫폼 바닥은 다시 보장되고, 플랫폼 각 셀의 바로 위 3블록 높이 공간이 비워집니다. 이 제거 높이는 바닐라 엔드 스폰 플랫폼의 상부 공간과 동일하며, 제거되는 블록은 바닐라와 동일하게 아이템을 드롭합니다. 플랫폼 바깥 영역은 건드리지 않습니다.

### 포탈 확장

자신이 만든 출발 포탈과 인접한 위치에 일반 엔드 포탈 생성기를 설치하면 포탈을 확장할 수 있습니다.

새 포탈 셀의 상대좌표와 동일한 위치에 반대 차원의 도착 플랫폼 셀이 1:1로 생성됩니다. 예를 들어 포탈이 ㄱ자 3칸이면 도착 플랫폼도 동일한 ㄱ자 3칸이 됩니다.

포탈은 최대 3 × 3 범위 안에서 확장할 수 있으며, 새 도착 플랫폼 셀이 생성될 대응 위치에 다른 블록이 존재하면 확장할 수 없습니다.

### 플레이어별 포탈

각 플레이어는 오버월드에서 출발하는 포탈 하나와 엔드에서 출발하는 포탈 하나를 각각 생성할 수 있습니다.

두 포탈은 서로 독립적이며 각 포탈은 자신의 도착 플랫폼을 별도로 가집니다.
