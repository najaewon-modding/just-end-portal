# Just End Portal

**Just End Portal**은 오버월드와 엔드의 원하는 위치를 직접 연결하는 엔드 포탈을 추가하는 Minecraft 모드입니다.

기존 엔드 포탈처럼 정해진 위치로 이동하는 대신, 플레이어가 직접 오버월드와 엔드의 위치를 지정하여 두 지점을 연결할 수 있습니다.

## 개발 환경

* Minecraft 26.1.2
* NeoForge 26.1.2.97

## 주요 기능

### 엔드 포탈 생성기

새로운 블록인 **엔드 포탈 생성기**를 사용하여 오버월드와 엔드 사이에 포탈을 생성할 수 있습니다.

1. 오버월드에서 원하는 위치에 엔드 포탈 생성기를 설치합니다.
2. 설치한 생성기는 오버월드에서 대기 중인 상태로 변경됩니다.
3. 대기 상태의 생성기를 가지고 엔드로 이동합니다.
4. 엔드의 원하는 위치에 생성기를 설치하면 오버월드와 엔드의 두 위치에 서로 연결된 엔드 포탈이 생성됩니다.

### 위치가 연결된 엔드 포탈

Just End Portal이 생성하는 포탈은 기존 엔드 포탈과 달리 지정된 위치끼리 직접 연결됩니다.

오버월드의 포탈에 들어가면 연결된 엔드의 포탈로 이동하고, 엔드의 포탈에 들어가면 다시 연결된 오버월드의 포탈로 이동합니다.

### 포탈 확장

생성한 포탈은 엔드 포탈 생성기를 추가로 사용하여 확장할 수 있습니다.

기존 포탈과 인접한 위치에 생성기를 설치하면 해당 위치가 새로운 포탈 블록으로 변경되며, 반대 차원에서도 동일한 상대 위치에 포탈 블록이 자동으로 생성됩니다.

반대편의 대응 위치에 다른 블록이 존재하는 경우에는 포탈을 확장할 수 없습니다.

### 플레이어별 포탈

각 플레이어는 하나의 연결된 포탈만 생성할 수 있습니다.

이미 오버월드와 엔드 사이에 연결된 포탈을 가지고 있는 플레이어는 새로운 포탈을 생성할 수 없으며, 기존 포탈을 확장할 수 있습니다.

## 개발 상태

현재 개발 중인 모드입니다.

기능과 세부 동작은 개발 과정에서 변경될 수 있습니다.
