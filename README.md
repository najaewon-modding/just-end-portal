# Just End Portal

오버월드와 엔드의 원하는 위치에 **단방향 엔드 포탈**을 만들 수 있는 NeoForge 모드입니다.

엔드 포탈 생성기 두 개를 서로 다른 차원에 설치하여 출발 포탈과 도착 플랫폼을 연결할 수 있습니다.

## 지원 환경

| 항목 | 값 |
| --- | --- |
| Minecraft | `26.1.2` |
| NeoForge | `26.1.2.97` |

## 주요 기능

- 오버월드 → 엔드 단방향 포탈 생성
- 엔드 → 오버월드 단방향 포탈 생성
- 플레이어별로 각 차원에 출발 포탈 1개씩 보유 가능
- 포탈을 최대 3 × 3 범위까지 확장 가능
- 출발 포탈 모양에 맞춰 도착 플랫폼도 동일하게 확장
- 도착 지점의 안전 공간 자동 확보
- Remote Getaway 발전 과제 달성 후 조합법 해금

## 엔드 포탈 생성기

### 기본 연결 방법

1. 오버월드 또는 엔드에서 원하는 출발 위치에 **엔드 포탈 생성기**를 설치합니다.
2. 반대 차원으로 이동합니다.
3. 원하는 도착 위치에 두 번째 생성기를 설치합니다.
4. 처음 설치한 생성기가 출발 엔드 포탈로 바뀝니다.
5. 두 번째 위치에는 도착 플랫폼이 생성됩니다.

출발 포탈에 들어가면 연결된 도착 플랫폼으로 이동합니다.

도착 플랫폼 자체는 포탈이 아니므로 자동으로 되돌아가지는 않습니다. 반대 방향으로 이동하려면 반대 차원에도 별도의 출발 포탈을 만들어야 합니다.

## 플레이어별 포탈

각 플레이어는 다음과 같이 최대 두 개의 독립적인 출발 포탈을 만들 수 있습니다.

- 오버월드에서 출발하는 포탈 1개
- 엔드에서 출발하는 포탈 1개

각 포탈은 자신의 도착 플랫폼을 따로 가집니다.

## 포탈 확장

자신이 만든 출발 포탈에 인접한 위치에 엔드 포탈 생성기를 추가로 설치하면 포탈을 확장할 수 있습니다.

- 최대 크기: `3 × 3`
- 출발 포탈의 상대적인 모양이 도착 플랫폼에도 그대로 적용됩니다.
- ㄱ자, 일자 등 직사각형이 아닌 형태도 만들 수 있습니다.
- 새 도착 플랫폼이 생길 위치가 막혀 있으면 해당 방향으로 확장할 수 없습니다.

## 도착 플랫폼

포탈을 통해 이동하면 연결된 도착 플랫폼 위에 도착합니다.

도착 지점이 막혀 있는 상황을 방지하기 위해 플랫폼 위쪽의 공간을 자동으로 비웁니다. 제거되는 일반 블록은 아이템으로 드롭되며, 플랫폼 바깥의 주변 지형은 변경하지 않습니다.

## 조합법

엔드 포탈 생성기 1개를 제작하려면 다음 재료가 필요합니다.

- 흑요석 4개
- 튀긴 후렴과 4개
- 엔드 수정 1개

```text
흑요석       튀긴 후렴과   흑요석
튀긴 후렴과  엔드 수정     튀긴 후렴과
흑요석       튀긴 후렴과   흑요석
```

조합법은 엔드 발전 과제 **머나먼 휴양지 (Remote Getaway)** 를 달성하면 해금됩니다.

## 설치

1. Minecraft `26.1.2`와 NeoForge `26.1.2.97`을 설치합니다.
2. Just End Portal JAR 파일을 서버와 클라이언트의 `mods` 폴더에 넣습니다.
3. Minecraft 또는 서버를 실행합니다.
